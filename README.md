# Quiz de Hebreus

Site estatico com uma trilha de perguntas sobre o livro de Hebreus.

## Como publicar no GitHub Pages

O repositorio esta configurado no GitHub Pages para publicar a partir da branch `main`, pasta `/ (root)`.

O site fica em:

`https://gbpontes22.github.io/Hebreus/`

## Como rodar localmente

Abra `site-quiz/index.html` no navegador.
